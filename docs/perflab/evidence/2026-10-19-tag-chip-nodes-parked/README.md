# Tag reaction chips as scene nodes (parked)

`tag-chip-nodes.patch` (on top of a1783bda4) ports `TagReactionView` (Saved Messages tags) to a `TagReactionChip` control node, like the ordinary chips: click opens the tag menu, the nine-part tag background (`ChatReactionTagBackgroundLayer`, geometry flipped like the native chip's) and count text live in the node layer, the effect player and fly-in anchor in the scene at the chip's frame. It builds, but the parity lab could not exercise it: the loaded Saved Messages history had no tagged messages (0 tag chips on both paths, 50 rows), so it is not applied. Re-apply with `git apply` and verify on an account with tagged Saved Messages (`chipNodes` / `chipViews` must be non-zero, `-PerfLabParityMutateChip 1` must be caught) before committing.
